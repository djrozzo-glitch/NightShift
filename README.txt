NIGHT SHIFT ALPHA 6.0 — THREE.JS 3D

Deploy: upload the ZIP to Netlify Drop or unzip and deploy the folder.
IMPORTANT: Three.js v0.160.1 is loaded from cdn.jsdelivr.net; players must have an internet connection and access to this CDN.

Controls:
Left click: place selected item. Right click: erase item.
Drag: rotate 360 degrees and tilt camera.
Shift + drag or middle mouse drag: pan.
Mouse wheel: zoom.
Q/E: rotate by 90 degrees.

Gameplay: preserved from Alpha 5.0: construction, DJs, visitors, prices, income, expenses, save/reset, time speed, demo club.
Saved layouts from older versions are read using existing browser localStorage keys.

Known limitations: graphics are procedural low-poly 3D, not detailed 3D assets; lighting and performance depend on browser/GPU. Browser interaction has not been end-to-end tested in this environment.
